## 📌 Descripción

Repositorio académico del **Grupo 8**, correspondiente a la asignatura **36884 – Arquitectura de Software** de la Universidad de las Fuerzas Armadas ESPE.

Aquí se almacenan las actividades, implementaciones, documentación técnica y ejercicios desarrollados durante los parciales, enfocados en el estudio de arquitecturas de software, servicios web y comunicación entre aplicaciones.

## 📂 Primer parcial: SINBBDD

En esta sección se encuentran las actividades relacionadas con la implementación de servicios web **SOAP y RESTful**, utilizando Java y .NET, sin conexión a una base de datos.

### 📚 Documentación técnica

- **Arquitectura.md:** documentación de la arquitectura de las soluciones.
- **Clases.md:** descripción de las clases utilizadas en las implementaciones.
- **Errores.md:** registro y explicación de errores encontrados.
- **Iniciar-donet-soap.md:** instrucciones para ejecutar el servicio SOAP desarrollado en .NET.
- **docker-compose.yaml:** configuración de servicios y contenedores mediante Docker Compose.
- **powerdesigner.png:** recurso gráfico relacionado con el diseño de la arquitectura.

## 🎯 Objetivos del repositorio

- Implementar y comprender servicios web SOAP y RESTful.
- Comparar soluciones desarrolladas con Java y .NET.
- Documentar la arquitectura y los componentes de las aplicaciones.
- Aplicar herramientas de control de versiones y trabajo colaborativo.
- Mantener organizadas las actividades y evidencias de cada parcial.
